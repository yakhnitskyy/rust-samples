# 04 — Arrays, Slices, and Vectors

Compare fixed-size arrays, borrowed slices, and growable vectors while practicing
safe indexing and collection transformations.

## Run

```console
cargo run
```

Examples 01–08 run in numeric order.

## Examples

1. Fixed arrays and repetition
2. Safe indexing
3. Shared slices
4. Mutable slices
5. Vector capacity and growth
6. Insertion and removal
7. Sorting and deduplication
8. Nested vectors and slice APIs

## Exercises

- Rotate an array using slice operations.
- Write a function that returns the average of an `&[f64]`.
- Flatten a nested vector with iterators.
