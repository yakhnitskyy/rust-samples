# 08 — Closures and Iterators

Learn closure capture, the `Fn` trait family, lazy iterator adapters, consumers,
custom iterators, and data-processing pipelines.

## Run

```console
cargo run
```

Examples 01–08 execute in order.

## Examples

1. Immutable capture
2. Mutable and `move` capture
3. `Fn`, `FnMut`, and `FnOnce`
4. Iterator adapters
5. Iterator consumers
6. Custom iterator
7. Lazy evaluation
8. Chaining and grouping

## Exercises

- Add a custom Fibonacci iterator.
- Rewrite a loop from another project as an iterator pipeline.
- Group words by their first character.
