# 07 — Generics and Traits

Write reusable code with type parameters and express shared behavior through
static and dynamic interfaces.

## Run

```console
cargo run
```

Examples 01–08 progress from generic functions to associated types and operator
implementations.

## Examples

1. Generic functions
2. Generic structs and methods
3. Traits and default methods
4. Trait bounds and `where`
5. `impl Trait`
6. Trait objects
7. Associated types
8. `Display` and `Add`

## Exercises

- Make `Pair` support values of two different types.
- Add a `Summary` implementation for a new article type.
- Implement `Sub` for `Point`.
