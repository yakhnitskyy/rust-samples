# 06 — Collections

Use Rust's standard collection types and recognize which access pattern each one
supports.

## Run

```console
cargo run
```

Examples 01–08 cover maps, sets, queues, heaps, and practical transformations.

## Examples

1. `HashMap`
2. Entry API and word counts
3. Grouping values
4. `HashSet`
5. Set operations
6. `VecDeque`
7. `BinaryHeap`
8. Choosing a collection

## Exercises

- Compute the most frequent word in a paragraph.
- Build a breadth-first traversal with `VecDeque`.
- Make a min-heap using `std::cmp::Reverse`.
