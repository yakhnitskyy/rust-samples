# 16 — Macros

Generate repeated Rust syntax with declarative macros and understand matching,
repetition, item generation, exports, and hygiene.

## Run

```console
cargo run
```

Examples 01–08 execute in order.

## Examples

1. Standard-library macros
2. Expression macro
3. Multiple match arms
4. Repetition
5. Item generation
6. Exported macro
7. Hygiene
8. Practical map and assertion macros

## Exercises

- Add optional trailing commas to a repetition macro.
- Generate several functions in one invocation.
- Extend `map_of!` to accept expressions as keys.
