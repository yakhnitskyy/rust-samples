# 01 — Basics

Learn variables and mutability, shadowing, scalar values, tuples, functions and
expressions, branching, loops, ranges, and destructuring.

## Run

```console
cargo run
```

The program runs examples 01–07 in order and labels every section.

## Examples

1. Variables, mutability, and constants
2. Shadowing and scalar types
3. Tuples and destructuring
4. Functions and expression values
5. Conditional expressions
6. Loops and returned values
7. Ranges and pattern destructuring

## Exercises

- Add a Celsius-to-Fahrenheit function.
- Print only even values from `1..=20`.
- Destructure a nested tuple without accessing fields by index.
