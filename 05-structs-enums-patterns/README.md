# 05 — Structs, Enums, and Patterns

Model data and behavior with Rust's product types, sum types, methods, and
exhaustive pattern matching.

## Run

```console
cargo run
```

Examples 01–08 run in order.

## Examples

1. Named structs
2. Tuple and unit structs
3. Methods and associated functions
4. Data-carrying enums
5. `Option`
6. `if let` and `let else`
7. Guards and destructuring
8. State modeling

## Exercises

- Add a rectangle intersection method.
- Model a traffic light and its permitted action.
- Extend the order state machine with a cancelled state.
