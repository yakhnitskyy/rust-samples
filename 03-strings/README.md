# 03 — Strings

Explore owned `String`, borrowed `str`, UTF-8, safe text processing, parsing,
formatting, and efficient string construction.

## Run

```console
cargo run
```

The program runs examples 01–09.

## Examples

1. `String` and `&str`
2. Conversions and ownership
3. Mutation
4. Concatenation and formatting
5. UTF-8 bytes and characters
6. Safe slicing
7. Search and split
8. Replace and parse
9. Building text efficiently

## Exercises

- Count words without allocating new strings.
- Return the first Unicode character as `Option<char>`.
- Build a comma-separated list using both `join` and a loop.
