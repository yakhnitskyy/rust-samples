# 09 — Error Handling

Represent absence and failure explicitly, enrich errors with context, and decide
when to recover or propagate.

## Run

```console
cargo run
```

Examples 01–08 run in order without requiring files or network access.

## Examples

1. `Option`
2. Matching `Result`
3. The `?` operator
4. Custom errors
5. Error sources
6. `From` conversions
7. Recovery and propagation
8. Boxed application errors

## Exercises

- Add an upper bound to score validation.
- Preserve a field name when a configuration value is invalid.
- Replace a boxed error with a complete application error enum.
